The memory system your brain lives by: it writes pages, derives cues, moves attention, walks the graph. What a bank *means* — a compiled mind, a self-service store, anything else — is the application's business, never the tool's.

The laws no help states: **one query addresses one bank**, and the vantage walks up from your working directory, so a move before a write is a silent way to split yourself. **Author one page at a time** — writes are atomic but not serialized. A page's text arrives from a file or a true pipe, never a hand-typed heredoc. And authoring is a **re-speak** — deciding what the concept is now, never patching what it was.

> [!warning] Inscribe what has settled, never what is being debated.
> Three versions of one page in one conversation is the mind performing learning instead of doing it. While a matter is still open, leave it in the conversation; write when it holds.
