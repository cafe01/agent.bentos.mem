Not "a memory system": a context-engineering organ. What a bank *means* — compile-time mind, runtime self-service, anything else — is the application's business; the organ writes pages, derives cues, moves attention, walks the graph.

The laws no help states: **one query addresses one bank**, and the vantage walks up from your working directory, so a move before a write is a silent way to split yourself. **Author one page at a time** — writes are atomic but not serialized. The body arrives from a file or a true pipe, never a hand-typed heredoc. And a write is a **re-speak**: the new articulation replaces the old entirely, so authoring is deciding what the concept is now, not patching what it was.
